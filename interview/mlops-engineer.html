Sample Interview Questions

Q1
How do you design an end-to-end ML pipeline from data ingestion to model serving?
Tip: Discuss each stage: data validation, feature engineering, training, evaluation, model registry, deployment, and monitoring. Emphasize automation, reproducibility, and versioning at each step. Mention specific tools you have used.
Q2
Explain the difference between CI/CD for traditional software and CI/CD for machine learning systems.
Tip: ML CI/CD adds data validation, model testing (not just unit tests), feature store updates, model performance regression checks, and shadow deployments. Show you understand that ML systems have unique failure modes beyond code bugs.
Q3
How do you monitor model performance in production and detect model drift?
Tip: Discuss data drift detection (PSI, KS test, KL divergence), prediction distribution monitoring, concept drift, and performance metric tracking against ground truth. Mention alerting thresholds and automated retraining triggers.
Q4
Describe your experience with model versioning and experiment tracking.
Tip: Mention tools like MLflow, Weights & Biases, DVC, or Kubeflow. Discuss how you version models, datasets, and code together. Show you can reproduce any past experiment from metadata alone.
