Sample Interview Questions

Q1
How do you approach securing a cloud environment from the ground up?
Tip: Structure the answer around identity (least privilege, MFA), network segmentation, encryption, logging and monitoring, patching, and IaC scanning. Ground it in the shared responsibility model.
Q2
Explain the shared responsibility model and how it changes your day-to-day security work.
Tip: Provider secures the cloud, you secure what you run in it — and it shifts across IaaS, PaaS, and SaaS. Give an example of a misconfiguration that falls on the customer.
Q3
Tell me about a cloud misconfiguration or vulnerability you found and how you fixed it.
Tip: Use STAR: how you detected it (CSPM, audit logs, scans), assessed blast radius, remediated it, and added a guardrail (policy or CI check) so it could not recur.
Q4
How do you manage secrets and credentials in cloud infrastructure?
Tip: Secret managers (AWS Secrets Manager, HashiCorp Vault), no keys in code, short-lived credentials and roles instead of long-lived keys, rotation, and audited access.
